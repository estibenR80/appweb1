# 🧠 Pronoun Power — Memory Card Game

An interactive digital memory game to practice **personal, possessive, and object pronouns**
in everyday contexts (school, home, friends).

## ▶️ How to open
Open `index.html` in any web browser. No installation needed.

## 🎮 What's included
- **20 cards (10 pairs):** each pair = a *sentence card* (with a blank) + its *matching pronoun card*.
- **2 wildcards:** 🎁 Extra Turn and 💥 Lose a Pair.
- **Flip on click** with `Match!` / `Try again!` feedback messages.
- **Color-coded pronouns:** 🔵 Personal · 🟣 Possessive · 🔴 Object · 🟠 Wildcard.
- **1–2 players** (toggle Solo mode) with automatic scoring and a winner banner.
- Tabs for **Rules (EN/ES)**, **Examples with explanations**, and a **Metacognition Reflection**.

## 📜 Rules
1. Board has 20 cards (10 pairs) + 2 wildcards, face down.
2. Flip **two cards** per turn.
3. Match a **sentence** with its **correct pronoun** → keep the pair and play again.
4. No match → cards flip back, next player's turn.
5. **Wildcards:** Extra Turn = flip again; Lose a Pair = return one pair.
6. Winner = most pairs when the board is clear.

## 🖨️ Physical version
Print this README's table on card stock, cut 20 cards (one side sentence, one side pronoun),
add 2 wildcard cards, shuffle face down, and follow the same rules above.
